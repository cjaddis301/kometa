# JMXD Overlay Artwork

The YAML configuration for the JMXD overlay stack is version controlled here

The active Kometa configuration expects local artwork beneath this directory, including:

```text
config/overlays/jmxd/
├── gradient.yml
├── gradient.png
├── resolution/
│   └── *.png
├── audio_codec/
│   └── *.png
└── edition/
    └── *.png
```
